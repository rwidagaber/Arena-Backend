# Admin Dashboard Implementation Plan

## Goal

Build a modern, data-driven Admin Dashboard for Arena Gym Management System that helps gym owners monitor business performance, member engagement, attendance, revenue, trainer utilization, and AI feature adoption.

---

# Dashboard Sections

## 1. KPI Summary Cards

Display at the top of the dashboard.

### Metrics

- Total Members
- Active Subscriptions
- Expiring Subscriptions (Next 7 Days)
- Today's Attendance
- Monthly Revenue
- Current Gym Occupancy %

### Purpose

Provide a quick overview of gym health.

---

## 2. Membership Analytics

### Member Growth

Line chart showing:

- New Members per Month
- Total Members Growth

### Subscription Status

Donut chart:

- Active
- Expired
- Paused

### Plan Distribution

Pie chart:

- Monthly Plans
- Quarterly Plans
- Yearly Plans

### Purpose

Track growth and retention.

---

## 3. Revenue Analytics

### Revenue Trend

Area or Line chart:

- Monthly Revenue
- Revenue Growth %

### Revenue By Plan

Bar chart:

- Revenue generated by each subscription plan

### Purpose

Measure financial performance.

---

## 4. Attendance Analytics

### Daily Attendance

Line chart showing attendance trends.

### Attendance Heatmap

Display attendance by:

- Day of Week
- Hour of Day

Example:

Rows = Hours
Columns = Days

Purpose:
Identify peak gym usage periods.

### Booking Funnel

Visual funnel:

Bookings
→ Attendance
→ Completed Sessions

Purpose:
Measure no-show rate.

---

## 5. Member Engagement

### Most Active Members

Table:

- Member Name
- Visits This Month
- Active Subscription

### At-Risk Members

Table:

- Member Name
- Last Attendance Date
- Days Since Last Visit

Criteria:

Member has not attended for 14+ days.

Purpose:
Retention and re-engagement.

---

## 6. Trainer Analytics

### Trainer Utilization

Bar chart:

- Trainer
- Utilization %

### Sessions Per Trainer

Bar chart:

- Trainer
- Number of Sessions

Purpose:
Balance trainer workload.

---

## 7. AI Analytics

### AI Feature Usage

Bar chart:

- Workout Plans Generated
- Nutrition Plans Generated
- AI Chat Usage

### AI Activity Summary

Cards:

- Total Workout Plans Generated
- Total Nutrition Plans Generated

## 8. Smart Insights Panel

Generate automated business insights.

Examples:

- Revenue increased 15% compared to last month.
- Attendance dropped 8% this week.
- 35 subscriptions expire within 7 days.
- Peak gym hours are 6PM–8PM.

Purpose:
Provide actionable insights for gym owners.

# Technical Requirements

## Localization and Egypt-Specific Requirements

- Primary client market is Egypt.
- All admin dashboard capabilities must support English (`en`) and Egyptian Arabic (`ar-EG`).
- Requirement is retroactive for current dashboard sections and mandatory for all upcoming sections.
- Localize KPIs, chart titles, legends, filters, table labels, validation/error messages, and insight text.
- Render user-facing timestamps in `Africa/Cairo` and currency values in `EGP` format.
- Any new admin controller endpoint must include localization-ready response messaging.

## Backend

Create dashboard endpoints in ArenaMVC that return aggregated statistics for admin pages.

ArenaAPI remains a shared backend for business workflows and event sources, not the home for admin controls.

Suggested endpoint:

GET /admin/analytics/v2/overview

Optional drilldowns:

GET /admin/analytics/v2/drilldowns/revenue-daily
GET /admin/analytics/v2/drilldowns/attendance-daily

Response should include:

- KPIs
- Revenue Analytics
- Membership Analytics
- Attendance Analytics
- Trainer Analytics
- AI Analytics

Avoid multiple API calls when possible.

- Modern UI
- Responsive
- Supports line, bar, donut, pie, heatmap
- Easy Angular integration

# Success Criteria

The dashboard should allow a gym owner to answer:

1. Is the gym growing?
2. Is revenue increasing?
3. Are members actively attending?
4. Which plans generate the most revenue?
5. Which members may churn soon?
6. How effective are trainers?
7. Are AI features being used?
8. What actions should the owner take today?
9. Is all dashboard content correctly localized in English and Egyptian Arabic for Egypt operations?
