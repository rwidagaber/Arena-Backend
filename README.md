# Gym-Platform

## Regional Baseline (Egypt)

- Client market: Egypt.
- All Arena projects must support English (`en`) and Egyptian Arabic (`ar-EG`).
- This localization requirement is retroactive for existing features/controllers and mandatory for all upcoming ones.
- Display dates/times in `Africa/Cairo` and format money in `EGP` for user-facing screens.
- Admin controls stay in ArenaMVC, and admin-facing localization must be implemented there.
